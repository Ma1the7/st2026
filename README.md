# Ереван, пешком — городской атлас

Полноценный адаптивный одностраничный сайт по загруженному макету.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для работы сайта не нужен сервер или сборка.

## Файлы
- `index.html` — вся структура и текст сайта.
- `styles.css` — оформление, адаптивность и CSS-иллюстрации.
- `script.js` — интерактивность: выбор интересов, сохранение мест и маршрута, схема карты, чек-лист и мобильное меню.

## Примечание
Иллюстрации нарисованы средствами CSS, поэтому сайт работает без локальной папки с изображениями. Шрифты Google Fonts загружаются при наличии интернета; при отсутствии сети используются системные запасные шрифты. Карта — схематичная, не предназначена для навигации.
